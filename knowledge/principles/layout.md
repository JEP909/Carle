# Layout & Space

Whitespace is the cheapest luxury and the clearest signal of quality. Compose
each layout for its content — never pour content into a fixed skeleton.

## Hierarchy first
- Every component has exactly **one** thing that matters most. Make it
  unmistakable with the fewest levers (size, weight, contrast, space, position).
  If three things shout, nothing is heard.
- Establish a clear reading path: where the eye lands first, second, third.
  Support it with alignment and spacing, not boxes and borders.

## Spatial rhythm
- Use a consistent base unit (4px or 8px) and keep all spacing on that scale.
  Inconsistent gaps read as carelessness.
- **Space communicates grouping**: related elements sit close, unrelated ones get
  air. Proximity does more than dividers. Reach for a divider only when space
  alone can't separate.
- Let the focal element breathe more than the chrome around it. Uniform padding
  everywhere reads as a template; intentional asymmetry reads as design.

## Composition
- Align to a grid, but break it deliberately for emphasis. A single off-grid
  element draws the eye.
- Prefer optical balance over mathematical centering. Adjust by eye.
- Density is a register choice: a dashboard is dense, a luxury landing is sparse.
  Match the domain.
- Don't default to "centered card: eyebrow, big heading, muted subhead, two pill
  buttons." That shape is the tell of a template. Let the content dictate form.

## Responsiveness & containment
- Constrain measure and focal sizes so the component holds together at the size
  it will actually be seen.
- Self-contained components should define their own world (background, padding)
  so they read correctly in isolation.
